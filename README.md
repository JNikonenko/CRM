# Гори

Личный планер в духе школьного дневника: день, неделя на развороте, месяц, списки по проектам и бэклог. Работает в браузере на ноутбуке и телефоне, бесплатно, без сервера и без сборки.

## Что умеет

- **День.** Задачи одного дня по важности. Полоска Пн–Вс сверху помогает выбрать любой день, стрелки листают по одному дню.
- **Неделя.** Разворот как в бумажном дневнике: Пн–Ср слева, Чт–Вс справа. Записываете задачу прямо в строку дня, листаете недели вперёд и назад.
- **Месяц.** Календарная сетка. Задачи можно перетаскивать между днями, «важные даты» выделены красным. Клик по числу открывает этот день, двойное нажатие по клетке добавляет задачу на этот день.
- **Проекты.** По колонке на каждый проект (без статусов «в работе» и т. п.). Порядок в колонке = важность: первая задача самая важная, перетаскиванием меняете приоритет или переносите задачу в другой проект. Сами колонки проектов тоже перетаскиваются за заголовок.
- **Бэклог.** Общий список задач без даты. Задача остаётся здесь, пока ей не поставят дату.
- Проект новой задачи выбирается справа от строки ввода.
- Порядок задач внутри дня и порядок внутри проекта хранятся отдельно, поэтому сортировка в календаре не ломает приоритеты в списке, и наоборот.
- Фильтр по проектам (чипы сверху), галочка «выполненные» на всех вкладках, заметки и чек-листы внутри задач, дублирование задач, кнопка «перенести хвосты на сегодня».
- На телефоне: долгое нажатие на задачу, чтобы перетащить. Можно «Добавить на главный экран», и Гори откроется как приложение.

## Синхронизация между устройствами

По умолчанию данные хранятся в браузере. Чтобы видеть одно и то же на ноутбуке и телефоне:

1. Создайте токен на [github.com/settings/tokens](https://github.com/settings/tokens/new?scopes=gist&description=Dnevnik) с правом **gist** (classic token).
2. На каждом устройстве: «Настройки» → вставьте один и тот же токен → «Подключить и синхронизировать». Гори сам найдёт общее хранилище.
3. Точка рядом с «Настройками» показывает состояние; нажатие на неё синхронизирует сразу.

Данные лежат в секретном gist’е вашего аккаунта (`dnevnik.json`). Изменения с разных устройств объединяются по задачам, побеждает более свежая правка. Ещё есть резервная копия в JSON (кнопки в настройках).

## Как опубликовать

GitHub → Settings → Pages → Build and deployment → **Deploy from a branch** → `main`, папка `/ (root)`. Через минуту Гори будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

GitHub Pages бесплатен для публичных репозиториев. Сайт публичный, но ваши задачи туда не попадают: они хранятся в браузере и в секретном gist’е.

## Запуск локально

```
python3 -m http.server 8000
```
и откройте http://localhost:8000.

## Файлы

- `index.html`, `styles.css`, `app.js` — всё приложение
- `vendor/Sortable.min.js` — перетаскивание ([SortableJS](https://github.com/SortableJS/Sortable), MIT)
- `sw.js`, `manifest.webmanifest`, `icon.svg` — установка на телефон и офлайн-режим
